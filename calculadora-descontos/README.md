<div>
<h1 align='center'>Calculadora de Descontos</h1>
<p>
Projeto desenvolvido com HTML, CSS e JavaScript com o objetivo de calcular o desconto de um determinado valor de forma automática.
O usuário informa o valor do produto, e o sistema exibe o valor final já com o desconto aplicado, de acordo com a forma de pagamento.
</p>
</div>

<div>
<h2>Funcionalidades</h2>
<ul>
  <li>Entrada do valor do produto</li>
  <li>Seleção da forma de pagamento</li>
  <li>Cálculo automático do valor final</li>
  <li>Exibição do valor com desconto</li>
  <li>Interface simples e intuitiva</li>
  <li>Layout responsivo</li>
</ul>
</div>
